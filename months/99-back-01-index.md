# 🗂️ Master Activity Index

This page is for the ten minutes before anything starts, on a morning with a
problem the printed day does not solve. Everything listed here already sits in
one of the twelve backup sections, and it runs in order of the thing you need
it to do rather than the month it belongs to. Each line carries a link and the
page it lives on, so the hunt takes a few seconds instead of a booklet.
